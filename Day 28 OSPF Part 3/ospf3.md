### Loopback Interfaces

- A virutal interface.
- Always up/up by default.
- Not dependent on physical interface.
- Used to indentify the router.

### OSPF Network Types: [YT](https://youtu.be/3ew26ujkiDI?si=qrYr6T2EjspJeGXl&t=313)

1. **Broadcast**: Enabled by default on Ethernet and FDDI interfaces.

2. **Point-to-Point**: Enabled on PPP and HDLC interfaces.

3. **Non-broadcast**: enabled on Frame Relay and X.25 interfaces.

COMMAND: `ip ospf network [TYPE]` in interface configuration mode.

##### Broadcast Netwrork:

- Enabled on ethernet and FDDI.
- Routers discover each other by sending/listening for OSPF HELLO messages on ip: 224.0.0.5
- A DR and BDR must be elected on each subnet (only DR if no OSPF neighbors)
- Routers which aren't DR or BDR will become DROTHERs.

- DR/BDR election:
  1. Highest OSPF interface priority.
  2. Highest OSPF router ID.

- First place becomes the DR for the subnet.
- Second place become the BDR for the subnet.

- How to make a router's interface priority higher: - `ip ospf priority [PRIORITY]` (0-255, default is 1) - Priority of 0 means the router will never become DR or BDR.
  NOTE: for the priority to take effect, restart the OSPF process.

- A full adjacency is only formed between the DR/BDR of the segment.
- A DR will form full adjacencies with all the routers in the segment. 
- DRothers will not exchange LSAs with each other.
- DRothers will form a full adjacency with the DR and BDR.

NOTE: Remember that Neighbor count is not the same as adjacency count.

#### Point-to-Point Network: [YT](https://youtu.be/3ew26ujkiDI?si=QPUU6sJHbAe98LO6&t=934)

- Enabled on PPP and HDLC interfaces.
- Routers discover each other by sending/listening for OSPF HELLO messages on ip: 224.0.0.5
- A DR and BDR are not elected on point-to-point links.
- Two routers will form a full adjacency with each other.
- The default encapsulation is HDLC.
- Identify which is DCE/DTE: `show controllers [interface]`

Configuration:
On a link either router will have DTE or a DCE interface
DTE will decide the clock rate.

- configure clock rate `clock rate bits-per-second` (default is 64000 bps)
- configure encapsulation `encapsulation ppp` (default is HDLC)

### OSPF Neighbor Requirements

1.  Must be in the same area.
2.  Interfaces must be in the same subnet.
3.  OSPF process must not be **shutdown**. (God knows what this means)

4.  OSPF hello and dead intervals must match. (default is 10s and 40s respectively)

- configure hello interval: `ip ospf hello-interval seconds`
- configure dead interval: `ip ospf dead-interval seconds`

5.  OSPF authentication must match. (default is no authentication)

- configure authentication: `ip ospf authentication [TYPE]`
- configure authentication key: `ip ospf authentication-key [KEY]`

6.  IP MTU settings must match (default is 1500 bytes) It is the max size of IP packet through the interface.

- configure MTU: `ip ospf mtu bytes`

7. Network type must match.

### OSPF LSA Types:

1. Type 1 (Router LSA)

- Every OSPF router generates this type of LSA.
- It identifies the router using its router ID.
- It also lists netwroks attached to the router. (ospf enbaled interfaces)

2. Type 2 (Network LSA)
- Generated by the DR of each 'multi-acess' network. 
- Lists the routers which are attached to the multi-access network. 

3. Type 5 (AS-External LSA)
- Generated by ASBRs to describe routes to destinations outside of the AS (OSPF doamin).
